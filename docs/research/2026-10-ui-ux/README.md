## 구현 검수 기록 (2026-10-11, 리비전 feat/ui-redesign-portfolio)

`dev-standard/policy/product-experience.md` 기준의 자체 검수다. 근거는 헤드리스
Chromium(390×844, 1280×800, light/dark)에서 실제 화면·DOM을 조작한 프로브
결과이며, 정적 검토만으로 통과를 적지 않았다. 스크린샷 사본은 소유자 검토 폴더
`D:\download\project\seoul-fit-fe\2026-10-11-ui-ux-redesign\`에 있다.

| 항목           | 결과      | 근거                                                                                                                                                                                                                                     |
| -------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 목표·흐름      | 충족      | 지도 → 마커/클러스터 → 상세 → 뒤로, 검색 → 선택 → 상세, 프리셋 칩, 설정 시트, 모바일 시트 3단(peek/half/full)이 데스크톱·모바일 모두 프로브로 완주됐다 (`interact.py` 10단계).                                                           |
| 시각적 위계    | 충족      | 한 색상군(한강 블루)과 라이브 포인트, 9색 카테고리 글리프, 카드 그림자 3단으로 지도 위 레이어가 구분된다. 라이트·다크 홈 화면 4장 확인.                                                                                                  |
| 문구 경계      | 충족      | 고객 화면 문구는 i18n 메시지에만 있고 내부 절차·에이전트 판단은 없다. 상류 오류 문구(ERROR-338 등)는 코드만 전달하고 화면에는 "실시간 도착 정보를 지금은 받을 수 없어요"로 바꿔 보여 준다.                                               |
| 상태·복구      | 충족      | 지도 SDK 실패 폴백·재시도, 위치 권한 없음 배너, 소스별 로드 실패, 라이브 데이터 미제공/권역 밖, 도착 정보 없음/제공 불가, 검색 결과 없음이 각각 이름 있는 상태로 보인다. 체감온도 결측(NaN) 노출은 수정했다.                             |

수정 후 재검수한 결함: 모바일 헤더 전체가 `pointer-events-none`에 가려
검색·메뉴를 누를 수 없던 문제, 클러스터러 라이브러리가 지도 생성 뒤에 붙어
마커가 비클러스터로 떨어지던 문제, 데스크톱 헤더에서 검색창이 눌리던 문제,
역·대여소에 '운영 여부 미확인'이 붙던 문제, "도서관" 검색에 도서관이 아닌 행사가
먼저 나오던 문제.
