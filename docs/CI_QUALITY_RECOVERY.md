# CI 품질 오류 복구 진행

2026-10-19. 공통 개선 작업
[HLG-68](https://youtrack.damecasol.com/issue/HLG-68)에 연결한다. 기본 브랜치는
master, 기준 소스는 bb2269a다. 현재 작업은 전용 worktree의 준비본이며 아직
게시하지 않았다.

최근 CI 38123096027은 타입·테스트에 성공했지만 Sonar 신규 품질 문제 178개로
실패했다. 읽기 전용 Sonar 조회에서 전체 미해결 359개와 신규 178개를 구분했다.
품질 기준·new-code baseline·제외 규칙은 낮추지 않는다.

컴포넌트 입력 85곳을 Readonly로 선언했다. 네이티브 fieldset/output/section으로
기존 접근성 역할을 표현하고 레이아웃 클래스를 유지했다. SDK ref는 실제 fieldset
타입으로 맞췄다. 알림 검사는 명시적 role 속성 대신 실제 접근성 역할을 확인하도록
수정했다. 빈 분기·미사용 import·중복 push·명시적 숫자 변환·선택적 접근·이벤트
타입 이름을 정리했다. 괄호/HTML 문자열 처리는 닫힘 구분자 기준의 선형 처리로
바꿨다. 날씨·혼잡도 API의 캐시 미스 후보 순회를 함수로 분리했으며 요청
순서·캐시·오류 응답·catch 경계는 유지했다.

중첩 조건은 같은 렌더링 순서를 가진 분기로 정리하고 상태 setter 이름을 맞췄다.
SDK와 위치 요청의 중첩 콜백을 분리했다. 검색 팝업 버튼에서 Escape를 누른 뒤
입력창 focus 이벤트가 팝업을 다시 여는 오류를 새 회귀 검사로 확인하고, focus
복구 뒤 닫기 상태를 마지막으로 적용하도록 고쳤다. 지도는 SDK의 키보드 이동
기능이 꺼져 있는 현재 설정에 맞게 비동작 Tab 정지점과 잘못된 방향키 안내를
제거하고 명명된 region으로 노출한다. 확대·축소·현재 위치·장소 선택 버튼은
유지한다.

CI의 의존성 설치와 커버리지 테스트를 한 번만 실행하고 같은 작업공간에서 Sonar를
분석한다. 기존 필수 검사 이름 `SonarQube quality gate`는 동일 실행의 품질 작업
성공과 명시적 검증 완료 출력이 둘 다 있어야 성공한다. 누락·실패·취소는 성공으로
바꾸지 않는다. Actions cache/artifact나 앱 의존성을 추가하지 않았다.

타입 검사, Jest 75개 suite/479개 테스트, 런타임 node 검사와 프로덕션 빌드가
통과했다. 이후 추가한 팝업 포커스 회귀를 포함한 검색 검사 15개도 수정 후
통과했다. ESLint 오류는 0개, 기존 경고는 99개다. 브라우저의 390px/데스크톱
레이아웃에 문서 가로 넘침은 없었다. 로컬 외부 지도 SDK·시설 API 연결은
실패했으므로 실제 지도 데이터/위치 기능의 종단간 성공으로 세지 않는다.

로컬 Sonar 규칙 대조에는 한글 IME의 keyCode 229 호환 처리와 팝업 자식 컨트롤의
이벤트 위임 진단이 남는다. 기존 한글 조합 검사와 새 팝업 focus/Escape 검사는
보존했다. 서버의 실제 재분석과 해당 진단의 개별 판단은 아직 남아 있다. 품질
기준·baseline· 제외 규칙을 낮추지 않았으며 신규 178개 전체 해결이나 원격 CI
복구를 완료했다고 표시하지 않는다. 인증 자격이나 배포 이미지는 변경하지 않았다.
