# CI 품질 오류 복구 진행

2026-10-19. 공통 개선 작업 [HLG-68](https://youtrack.damecasol.com/issue/HLG-68)에 연결한다.
기본 브랜치는 master, 기준 소스는 bb2269a다. 현재 작업은 전용 worktree의 준비본이며 아직 게시하지 않았다.

최근 CI 38123096027은 타입·테스트에 성공했지만 Sonar 신규 품질 문제 178개로 실패했다.
읽기 전용 Sonar 조회에서 전체 미해결 359개와 신규 178개를 구분했다. 품질 기준·new-code
baseline·제외 규칙은 낮추지 않는다.

컴포넌트 입력 85곳을 Readonly로 선언했다. 네이티브 fieldset/output/section으로 기존
접근성 역할을 표현하고 레이아웃 클래스를 유지했다. SDK ref는 실제 fieldset 타입으로 맞췄다.
알림 검사는 명시적 role 속성 대신 실제 접근성 역할을 확인하도록 수정했다.
빈 분기·미사용 import·중복 push·명시적 숫자 변환·선택적 접근·이벤트 타입 이름을 정리했다.
괄호/HTML 문자열 처리는 닫힘 구분자 기준의 선형 처리로 바꿨다. 날씨·혼잡도 API의
캐시 미스 후보 순회를 함수로 분리했으며 요청 순서·캐시·오류 응답·catch 경계는 유지했다.

현재 묶음은 타입 검사, Jest 74개 suite/465개 테스트, 런타임 node 검사에 통과했다.
ESLint는 오류 0개, 기존 경고 99개다. 네이티브 요소 전환 후 ref 타입 오류와 직접 role
속성을 기대한 테스트 1개가 먼저 실패했으며 실제 타입과 역할 검사로 수정하고 재통과했다.

남은 작업은 새 문자열 경계 회귀 검사, 중첩 조건·상태 setter 등 나머지 진단의 의미 있는
수정, 빌드·화면 확인, 실제 CI/Sonar 재분석이다. 아직 신규 문제 178개 전체 해결이나
원격 CI 복구를 완료했다고 표시하지 않는다. 인증 자격이나 배포 이미지는 변경하지 않았다.
